# @groupsum/document-studio

React document builder and document studio component package for Groupsum applications.

## Install

```bash
pnpm add @groupsum/document-studio
```

## Use

```tsx
import { DocumentStudio } from '@groupsum/document-studio';
import '@groupsum/document-studio/style.css';
```

## Scripts

- `pnpm run test`
- `pnpm run typecheck`
- `pnpm run build`
