# @groupsum/docmaker-sdk

React document builder and PDF hub component package for Groupsum applications.

## Install

```bash
pnpm add @groupsum/docmaker-sdk
```

## Use

```tsx
import { PDFHub } from '@groupsum/docmaker-sdk';
import '@groupsum/docmaker-sdk/style.css';
```

## Scripts

- `pnpm run test`
- `pnpm run typecheck`
- `pnpm run build`
